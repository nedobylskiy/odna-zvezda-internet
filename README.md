# Сеть Одной звезды

Статический сайт вымышленного интернета вселенной «Одна звезда». Поисковая главная связывает независимые сайты внутри мира. Каждый сайт имеет собственный дизайн, главную и внутренние страницы с постоянными HTML-адресами.

## Разработка

Требуется Node.js 20+; сторонних пакетов нет.

```sh
npm run build
npm run check
python3 -m http.server 8000 -d dist
```

Для просмотра локально соберите сайт и откройте `http://localhost:8000/`. Все внутренние пути начинаются с корня домена.

## Публикация

Workflow `.github/workflows/pages.yml` собирает `dist` и публикует его через GitHub Pages при push в `main`. Публичный адрес в `src/config.json` — `https://одна-звезда.рф/`; он используется для canonical, sitemap и внутренних ссылок. Домен должен быть отдельно подключён в **Settings → Pages → Custom domain** и DNS. Источник публикации — **GitHub Actions**.

## Добавление узла

Добавьте запись в `src/content.json` → `sites`, а затем модель сайта в `src/microsites.js`: тему, заголовок, навигацию и внутренние страницы. Тема оформляется в `assets/microsites.css`. Поле `domain` образует реальный путь `/<domain>/`, а разделы — `/<domain>/<page>/`. Статьи энциклопедии находятся внутри `/knowledge.wiki/<article>/`. Старые адреса `/sites/...` автоматически ведут на новые и исключены из sitemap.

Для сайтов со своей структурой лендинга можно добавить отдельный рендерер: Olympic находится в `src/render-olympic.js`, его стили — в `assets/olympic.css`. Верхняя служебная ссылка ведёт обратно в общий поиск.

Официальный портал Земли находится в `src/render-earth.js`, его стили и счётчик — в `assets/earth.css` и `assets/earth.js`. Новости с зоной `earth` в `src/content.json` выводятся на главной `/portal.ue/` и получают отдельные страницы в `/portal.ue/news/`.

На всех страницах земного портала показывается «Центральнодемное время» по UTC. На `red.mars` показывается среднее марсианское время нулевого меридиана (MTC) и номер сола; расчёт в `assets/mars-clock.js` использует упрощённую формулу NASA Mars24 с фиксированной разницей TT−UTC и не учитывает часовые смещения отдельных куполов.

Сборка создаёт страницы, поисковый индекс и sitemap. Подсказки появляются под строкой при вводе, работают с мышью и клавиатурой. Поиск и смена точки обзора не требуют сервера. Новости в `src/content.json` служат исходной разметкой; для переключаемых лент синхронизируйте записи в `assets/app.js`.

Поиск выполняется в браузере по небольшому статическому индексу и меняет порядок выдачи по точке обзора. Запросы `/search/?q=...` сами по себе не образуют индексируемые страницы; поисковики получают HTML каждого узла через каталог и sitemap. Вымышленные домены не являются реальными DNS-именами.

Фанатский форум `warandlove.venus` собирается из `src/forum.js` и `src/render-forum.js`, оформление — `assets/forum.css`. Каждый раздел и каждая тема имеют собственную статическую страницу; вход и регистрация показаны как временно недоступные и исключены из sitemap. В каталоге форум находится в разделе «Фильмы, сериалы и музыка».

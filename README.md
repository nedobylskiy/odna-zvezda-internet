# Сеть Одной звезды

Статический сайт вымышленного интернета вселенной «Одна звезда». Поисковая главная связывает независимые сайты внутри мира. Каждый сайт имеет собственный дизайн, главную и внутренние страницы с постоянными HTML-адресами.

## Разработка

Требуется Node.js 20+; сторонних пакетов нет.

```sh
npm run build
npm run check
python3 -m http.server 8000 -d dist
```

Для просмотра локально установите `basePath` в `src/config.json` равным `""`, соберите сайт и откройте `http://localhost:8000/`. Перед публикацией верните `"/odna-zvezda-internet"`.

## Публикация

Workflow `.github/workflows/pages.yml` собирает `dist` и публикует его через GitHub Pages при push в `main`. В настройках репозитория выберите **Settings → Pages → Build and deployment → GitHub Actions**. Пока используется адрес `https://nedobylskiy.github.io/odna-zvezda-internet/`. Если подключите свой домен, обновите `origin` и `basePath` в `src/config.json` до публикации: например `"origin": "https://одна-звезда.рф", "basePath": ""`. Тогда canonical, sitemap и все внутренние ссылки будут указывать на новый адрес. Домен подключается отдельно в настройках Pages и DNS.

## Добавление узла

Добавьте запись в `src/content.json` → `sites`, а затем модель сайта в `src/microsites.js`: тему, заголовок, навигацию и внутренние страницы. Тема оформляется в `assets/microsites.css`. `slug` образует URL `/sites/<slug>/`, а разделы — `/sites/<slug>/<page>/`. Вымышленный `domain` показывается в интерфейсе. Статьи `knowledge.wiki` лежат по адресам `/sites/knowledge/<article>/`.

Для сайтов со своей структурой лендинга можно добавить отдельный рендерер: Olympic находится в `src/render-olympic.js`, его стили — в `assets/olympic.css`. Верхняя служебная ссылка ведёт обратно в общий поиск.

Сборка создаёт страницы, поисковый индекс и sitemap. Подсказки появляются под строкой при вводе, работают с мышью и клавиатурой. Поиск и смена точки обзора не требуют сервера. Новости в `src/content.json` служат исходной разметкой; для переключаемых лент синхронизируйте записи в `assets/app.js`.

Поиск выполняется в браузере по небольшому статическому индексу и меняет порядок выдачи по точке обзора. Запросы `/search/?q=...` сами по себе не образуют индексируемые страницы; поисковики получают HTML каждого узла через каталог и sitemap. Вымышленные домены не являются реальными DNS-именами.
